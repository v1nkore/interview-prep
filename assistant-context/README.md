# Контекст ассистента

Приватный бэкап правил, которые Codex использует между сессиями. Файлы названы не `AGENTS.md`, чтобы они не применялись автоматически при работе внутри этого репозитория.

| Бэкап | Рабочий файл |
|---|---|
| `AGENTS.global.md` | `~/.codex/AGENTS.md` |
| `AGENTS.money.md` | `~/Documents/ChatGPT/ДЕНЬГИ/AGENTS.md` |
| `AGENTS.mental.md` | `~/Documents/ChatGPT/МЕНТАЛКА/AGENTS.md` |

При восстановлении копируй содержимое в соответствующий рабочий файл. Если рабочая и резервная версии расходятся, сначала сравни даты и сохрани более новые материальные решения; не заменяй файл вслепую.
