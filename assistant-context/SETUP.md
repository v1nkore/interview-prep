# Сетап пользователя

Обновлено: 8 ноября 2026 года.

## Основная рабочая машина

- MacBook Air 15″ с Apple M5.
- 16 ГБ объединённой памяти.
- SSD 512 ГБ.
- macOS, shell `zsh`.
- Основные сценарии: C#/.NET backend, Docker, базы данных, браузер, облачные AI-инструменты, иногда OBS, лёгкий монтаж и эксперименты с небольшими локальными моделями.

## Windows-ноутбук

- MAIBENBEN X577.
- AMD Ryzen 7 7735H.
- Встроенная Radeon 680M.
- NVIDIA GeForce RTX 4060 Laptop, до 140 Вт.
- 16 ГБ RAM.
- SSD 512 ГБ.
- QHD IPS 2560×1440, 165 Гц.
- Аппаратный MUX.
- Windows 11 Pro x64; последняя подтверждённая версия — 25H2.

## Маршрутизация рекомендаций

- Рабочая разработка и macOS-инструкции: MacBook.
- Игры, NVIDIA, MUX, Windows-драйверы и Windows-специфичные действия: MAIBENBEN.
- Для советов по апгрейду сначала учитывать точную машину и сценарий; не смешивать unified memory Mac с обычной RAM Windows-ноутбука.
